# Security

If you find a vulnerability in this Action, please report it through GitHub's private vulnerability reporting on this repository (Security tab → Report a vulnerability). Please do not open a public issue for it.

What we commit to:

- We confirm receipt within 5 business days and keep you updated until the issue is resolved.
- After a fix, we publish a GitHub security advisory on this repository describing the affected scope.

What is in scope: anything that makes the Action send a credential to the server it observes, send a request to a host other than the one you named, write outside the workspace, or put text from the observed server into a pull request comment in a form that is not inert.
